# M4-04 单任务耗时、质量与费用

仅使用公开的虚构开发样例。以下是单并发机器处理时间。上传、排队、人工校对时间及独立保留集质量尚待门店试用测量。

## 照片 OCR（2026-11-24）

在 Windows 本机运行 `.venv/Scripts/python.exe -m scripts.eval_photo_ocr`，由 Pillow 生成三张 720 × 180 白底黑字 PNG，字体为微软雅黑。计时从调用实际 `recognize_photo` 到返回文字，包括 PNG 处理、启动子进程与 Windows 中文 OCR。逐张顺序运行一次。

| 图片 | 字号（像素） | 预期两行文字 | 耗时 | 忽略空白后全文一致 |
| --- | ---: | --- | ---: | --- |
| large | 42 | 样例甲区 / 热水器不点火 | 322 ms | 是 |
| small | 22 | 样例乙区 / 回访安排在周五 | 272 ms | 是 |
| mixed | 32 | 样例丙区 / 设备型号 DEMO-12 | 264 ms | 是 |

实测中位数 272 ms。原始输出在汉字间插入空格，三张图均需忽略空白才能全文匹配。每张图调用本机 OCR 一次，云 OCR 请求为 0，按调用计的云 OCR 费用为 0 元。本次未计电费、设备和人工成本。倾斜、手写、反光和现场照片的识别质量仍需取样。

| 用例 | 自动判分 | 耗时 | 模型调用 | 实测 tokens | 模型费用估算（元） |
