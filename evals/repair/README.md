# M3-04 维修问答对照评测

2026-11-19 使用同一个 `deepseek-flash`、6 个虚构问题和 3 条合成说明书摘录。自动判分检查适用型号、引文来源和预期故障含义。缺型号、型号无资料和紧急风险场景需要停止普通回答。对照组返回资料不足且没有建议可通过这些保护用例，只有 RAG 组验证本地分流到具体原因及紧急提示。

| 组别 | 符合预期 | 模型调用 | 总 tokens | 单用例耗时中位数 |
| --- | ---: | ---: | ---: | ---: |
| 直接问同一个模型 | 3/6 | 6 | 3158 | 608 ms |
| 同模型提供全部样例资料 | 4/6 | 6 | 4905 | 903 ms |
| 维修助手 RAG | 5/6 | 3 | 1796 | 305 ms |

- 直接问模型时，3 个有明确答案的虚构设备用例均因缺资料而停止回答。
- 全部资料组在 B 型 E3 回答中混入 A 型原句，对未覆盖型号返回资料冲突。
- RAG 在 B 型 E3 和自然描述的已覆盖现象上返回正确来源，缺型号、无依据和紧急输入由本地规则分流。A 型 E3 检索到了对应资料，模型仍返回依据不足，助手保留原页链接。

耗时按整条用例计量，包含 RAG 的本地分流。上表为一次小规模开发评测，成本以实际调用和 token 计量。费用金额、现场可用性和跨手册覆盖留待后续核对。师傅评审时需逐项确认适用机型、必要条件、原句是否支持结论、缺口提示和现场可用性，并复核紧急输入提示。此次报告没有实地维修样本和师傅签字。
