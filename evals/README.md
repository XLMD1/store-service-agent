## 使用边界

- 库房、型号、客户、日期、数量和测试主体都是构造数据；不代表真实盘点、人员授权、付款或维修事实。姓名和联系字段缺失时保留空值。
- `independent_states`是互相独立的前置快照，不得一起导入同一份账；`continuous_scenario`从未建账开始，按步骤顺序演算。独立AC每次重置前置状态，不能继承上一项的余额。
- `expected`只是测试预期，`confirmation_required`只是用例要求；它们不能充当人工确认或服务端操作回执。示例主体没有密码、会话或真实账号。
- 2026-10-29用户同意开发样例权限沿用PRD产品建议；真实人员职责仍待业务核对，实际授权由后续后端配置和操作时校验决定。
- M1用真实PostgreSQL验证约束、并发、事务和幂等；静态数据核对不能替代这些验证。只有实际执行后才能填写结果、环境、命令和证据。
- 全部现有AC可用于开发和回归。调优样本、未用于调优的保留样本、由业务人员独立准备的任务分别管理；后两类目前未收集，不能把公开AC换个标签当作独立质量评测。
- 真实客户材料、内部手册原件、数据库和凭据保存在仓库之外。本目录只提交获准公开的脱敏标注或虚构数据；材料是否已取得与获准使用，在开发计划记录。
