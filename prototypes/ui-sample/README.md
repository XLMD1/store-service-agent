# 门店助手 · C 方向 HTML 视觉样板

基于已选 C 首页与七个手机核心页，先固定视觉语言和共用组件。整理日期：2026-10-28。

## 查看

直接打开 `index.html` 可浏览首页；推荐在项目根目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/prototypes/ui-sample/`。图标已内联，直接打开 HTML 也能显示；HTTP 方式便于浏览概念图册和本地预览。

- `index.html`：手机工作台，按 C 的任务区 → 2×2 高频入口 → 待核对 → 最近任务 → 底部导航组织。
- `ui-kit.html`：配色、表面材质、按钮、表单、状态、列表、库存数字与图标样板。
- `tokens.css`：颜色、字体、间距、圆角及材质类。
- `ui.css`：同一套按钮、字段、列表、导航、对话框等组件。
- `app.js`：仅用于视觉样板的本地交互，没有服务端请求或存储。

## 本轮 UI 决策

- 手机逻辑宽度以 390px 为基准，页面可适应窄屏；电脑上保持居中的手机业务视图。未扩展桌面业务布局。
- 深墨青 `#17313B` 放任务区，主操作 `#0F766E`，正文与列表白底，缺字段提示用琥珀色与明确文字。
- 中文使用 Microsoft YaHei / PingFang SC / Noto Sans CJK SC 系统字体链，无外部字体请求。正文 14px、模块标题 18px、任务标题 23px；按钮及字段最小高度 44px。
- 规则列表使用分隔线，快捷功能轻边框，阴影仅用于浮层。
- 用户明确允许 SVG 图标，因此使用自绘的统一描边 SVG，不增加图标包依赖。
- 纹理为独立生成的位图；CSS 通过通用 `.material-ink` 引入，其他页面可以直接复用。

## 交互范围

输入和照片可在任务预览中查看；支持清空输入校验、照片移除、待核对弹层、示例地址检索、库房筛选、视觉组件页跳转及原概念图链接。剪贴板权限不可用时提示手动粘贴。弹层可按 Escape 关闭。

样板明确使用示例数据；任务预览不执行 AI 识别、维修诊断或正式业务登记，不持久保存客户资料。七个完整业务页仍以概念图作为后续页面设计依据。本样板不宣称完成后端、资料接入或业务流程。
