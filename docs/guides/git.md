# Git与GitHub规范

仅在提交、推送或创建PR时阅读。本文规定格式，不额外授予Git操作权限；只处理当前任务相关文件，保留其他修改与暂存内容。

## 提交信息与PR标题

统一使用“英文类型: 中文说明”：

```text
<type>: <中文简要说明>
<type>(<scope>): <中文简要说明>
```

- 类型与可选作用域使用小写英文；冒号为英文半角，后留一个空格。
- 中文说明描述实际变更，简洁具体，不使用“更新一下”“修改代码”等含糊表述。
- 正文按需要使用中文，说明原因、影响和验证；PR按最终实现范围撰写，不记录无关对话过程。

| 类型 | 使用场景 |
| --- | --- |
| `feat` | 新增功能 |
| `fix` | 修复问题 |
| `docs` | 文档变更 |
| `refactor` | 不改变行为的重构 |
| `test` | 测试变更 |
| `perf` | 性能改进 |
| `ci` | 持续集成配置 |
| `chore` | 依赖、工具或其他维护 |

```text
docs: 整理项目文档与按需阅读入口
feat(inventory): 添加库存预留功能
fix: 修复预留提货重复扣减可售数量的问题
```
