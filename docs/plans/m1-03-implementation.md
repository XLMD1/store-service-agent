# M1-03 入库与确认基础实施记录

依据：PRD FR-08及T0规则、架构第17节、阶段计划M1-03。用户明确进入本阶段，作为M1-02获准继续的依据；完成后等待审核，不实施出库/留货/提货。

## 实施选择与边界

- 复用现有草稿、操作、权限和回执路径，按kind支持`inventory_inbound`；不另建绕过人工确认的直接入库接口。
- 入库只改变H和A，R不变；确认时锁定库存账户并复核版本/权限/时间边界。余额、入库原单、流水与回执同事务提交。
- 原单保存发生日期或精确时刻及其精度，不把日期补成午夜；登记时间单独记录。T0及以前拒绝；T0同日仅知日期时，人工说明after及依据才可确认，unknown保存待补信息。
- 成功重放先核验原绑定和当前权限，再返回当时回执，不因后续余额变化而失败。草稿修改和对象版本变化使旧确认失效。
- 新增入库表单及待核对列表；进出货职责可办理入库，负责人兼有建账权限。回执、预计影响、实际余额均来自后端。
- 当前审核页从测试库备份恢复到独立`store_agent_m1_review`，保留此前账号和样例。自动测试仍只清理`store_agent_m1_test`；不触碰真实业务库。
