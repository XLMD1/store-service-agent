# M2-01 来源保存与受控阅读

本阶段按[开发计划](development-plan-v1.0.md#7-m2售后档案闭环)先交付手工原文。以虚构材料验证，照片规格与正式保留规则按 D-04 核定。

1. 在专用 PostgreSQL 库验证登录、CSRF、原文无损保存、同一请求重试、未归档隔离、撤权及重启恢复。先写接口测试，再加入 `app/sources/` 与 Alembic 迁移。
2. 原文和提交元信息随同一个数据库事务保存。读取每次重新校验 `service.read` 及提交者，提交校验 `service.draft`。同提交者、同请求标识、同内容返回原结果，内容变化返回冲突。
3. 沿用 C 方向接入上传和阅读。验证成功状态来自后端，失败保留输入，刷新可回到保存结果。同步页面编号、截图与验证记录。
4. 依据 D-04 完成照片限制与保存方式核对，再验证原图、识别失败后保留以及跨记录访问边界。关联授权随草稿和档案阶段落地。
