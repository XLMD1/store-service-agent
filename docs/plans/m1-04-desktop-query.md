# M1-04 查询选择与电脑页面

2026-11-02 / 本机验证完成，待用户审核，未提交或推送。用户已选择既有C方向侧栏样板并授权增加电脑端/手机端切换。

## 设计与范围

- 查询初始两项留空；型号必选，但可明确选择“全部型号”（内部值all），此时overview省略model_id；具体型号仍传稳定ID。不自动查询或恢复上次条件。
- 库房输入保留名称检索，旁边“选择库房”始终列全部已登记库房，不受已输入名称过滤。选项仅更新对象并清除旧结果；重名附区分编号，停用保留说明。用原生按钮及可见焦点，Escape关闭列表。
- 用户已选用原核心前端的左导航/右业务区，而非继续扩展居中布局。复用C tokens、SVG、纹理；只加入已实现且有权限的业务导航，不搬入样板模拟数据或未实现售后入口。
- 页顶提供电脑端/手机端切换。只切换容器样式，不重新渲染表单、请求接口或改变权限；切换保留正在输入的内容和草稿。首次按窗口宽度选择，手动选择在当前页面会话内保留；刷新后按窗口宽度初始化。窄屏电脑模式将侧栏改为紧凑侧栏（保留左侧导航），保证能切回手机端。

## 实施与验证

1. 修改tests/web-inventory.test.cjs：全部型号请求省略model_id；填名称后完整列表可直接切换且不自动查询。先验证失败，再改app/web/inventory.js和app.css。
2. 修改app/web/app.js的shell及app.css：加入当前权限侧栏和模式切换；验证切换不重新生成内容、不丢失字段和草稿，导航在各页保持。
3. 浏览器实际核对全部/单型号、已填库房切换、重名和未建账、手机/电脑及键盘；运行全部生产JS、语法和样板检查，文档双版及截图同步。纯前端不重跑库存数据库并发测试。

## 审核重点

空白型号不请求；all不是后端UUID；切换库房不显示旧结果；输入变化不能继续使用旧ID；页面模式不触发表单丢失；侧栏不能显示无权限办理入口；320px无溢出，键盘可关闭选择区。
