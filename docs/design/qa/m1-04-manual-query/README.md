## 当前行为与根因修复

原页面会读取state.inventorySearch并在渲染后requestSubmit，候选点击也会requestSubmit。本轮删除两处自动触发及旧条件恢复：每次进入库存页，库房和型号均为空；型号有原生required及提交前校验；必须明确提交查询。选择候选只确认库房并提示点击查询；填写字段本身不显示结果。支持键盘明确提交，不牺牲键盘可用性。

所有启用按钮保持pointer光标，补齐次按钮/候选/链接/折叠入口的鼠标提示；主按钮深青绿悬停、次按钮浅青绿悬停，页头按钮仍保留白字。禁用按钮为not-allowed，主按钮禁用时不应用hover。没有增加重复“点击”工具提示，也没有移动布局或改变权限。
