# M3-03 维修辅助与反馈

在隔离测试库登录虚构师傅账号，从日常工作进入「维修辅助」。明确型号后提交样例 E3 及现场条件，页面展示故障含义、带条件的原文建议及对应印刷页。打开引用能到原页，反馈提交后有保存回执。390 px 手机视口下内容和可用宽度同为 375 px。

接口回归覆盖缺型号、型号无资料、仅索引关键词时展示原页、紧急输入分流、编号引用越界、资料停用以及反馈的本人权限。前端回归确认更改型号或现象会清空旧回答和反馈。

只读复验正式 GB1S B 版三页摘录时，发现先命中的其他关键词可能挤掉用户当前现象的对应行。调整为优先使用本次问题的检索条件选段，正式摘录的三条用例均定位正确原句，另有 5 项本次相关回归通过。此检查在本机完成，正式摘录未用于模型调用。

## 本机审核版

2026-11-19 已部署到 [8002 维修辅助](http://127.0.0.1:8002/#repair-assistant)。迁移前已备份并完整读取备份，数据库升级至 `0022_repair_answers`，迁移一致性检查通过。迁移前后 15 张现有表的行数和内容指纹一致，保留 GB1S B 版已确认的 3 页索引和摘录。

部署前相关后端 47 项、前端 78 项测试及 lint、类型检查通过。8002 浏览器核验了登录后的维修辅助入口、缺型号追问和燃气异味测试输入的本地分流。正式机型的生成答复和现场可用性由师傅审核。

8002 审核时，单独查询 `L1PB30-G28B1S` 的 `E3` 曾返回原页及合并的降级提示。已核对第 19 页有明确的故障含义。修复后，单独查询且已核对摘录有唯一的明确故障码定义时，直接在本机返回该条原文和引用。其他问答使用分开的摘录缺失、模型不可用、引用无效或依据不足提示。相关后端 47 项通过，8002 浏览器复验已显示故障含义和 B 版第 19 页链接。

续测 `L1PB30-G28B1S` 的「供暖系统水压异常降低」时，模型引用校验失败曾只留下第 20 页链接。修复后，未填现场检查结果且恰好命中已核对表格现象时，在本机列出匹配行的可能原因。8002 浏览器复验显示「供暖系统渗漏」「补水阀未拧紧」，两项均引用 B 版第 20 页，页面保留需结合现场检查核对的提示。该复验未调用模型。相关后端 47 项、前端 78 项通过。

审核时发现，同样的 `E4` 和现场记录重新提交后，模型有时把一条包含处置指令的说明书原句归为「检查前提」。现已过滤这类误标，并按账号、请求摘要、资料修订和模型提示复用已校验答复。使用虚构资料验证相同输入只调用模型一次，修改现场条件或修订摘录后重新整理。只读复验第 19 页已核对摘录的分类，全程未向模型重发正式摘录。相关后端 47 项通过。
