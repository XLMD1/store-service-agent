# M2-05 工费台账本机核对

使用 Edge 浏览器视口、回环 FastAPI 和专用 PostgreSQL。师傅、地点、工费、结算日期和补录起点均为虚构样例。

真实浏览器样例中，老板给同一安装安排两位师傅。确认应付后，其中一人已扣 100 元，另一人待付 50 元。汇总按状态分别显示，师傅各自只看到自己的工费。补录使用负责人确认的起始日。后端另验证未核对申报不计入应付、结算并发只有一笔成功、回执重放、已结状态更正及早于起始日的旧单被拒绝。

专用 PostgreSQL 完整回归 285 项通过。Edge 端到端 1 项通过，耗时 11.45 秒。前端 71 项、lint、类型检查和静态 mock 构建通过。

实际结清起点和旧账尚待负责人核实。首个补录入口按一位师傅逐单录入。实体设备与门店试用待验。

## 师傅账号管理

2026-11-13 在独立测试库通过 Edge 端到端检查。负责人从工费台账进入师傅账号页，创建虚构账号后安排列表可选，师傅可以登录。停用后，师傅原会话失效，安排列表移除该账号。重新启用后，安排列表恢复该账号，旧会话仍失效。

账号和工费 PostgreSQL 集成测试 45 项、Edge 端到端 1 项、前端 71 项均通过。lint、类型检查和静态 mock 构建通过。
