## 跨人来源核对

2026-11-18 在独立回环页面及专用 PostgreSQL 使用虚构来源验证。负责人从「售后来源 → 我的来源」打开原件并生成草稿，在「授权核对」指定接单测试账号并确认。接单账号从「授权给我」成功打开原文和草稿，提交人撤销后，原件直达链接拒绝访问。授权成功的页面已在本轮会话截图。实体设备未覆盖。

集成测试另覆盖原图、角色限制、按来源隔离、旧归档预览失效、账号停用及旧请求重放。工费和售后试用样本见[用例](../../../plans/m2-test-cases.md)。

2026-11-18 本机 8002 备份数据库后升至 `0018_source_review_grants`。核对了账号、角色、来源、草稿、档案、工作单和工费七张表的行数及内容指纹。现有登录会话可打开「授权给我」列表及原件页「授权核对」表单。本机售后、来源、账号及工费回归 84 项通过，前端 73 项通过。跨账号写入在独立测试库验证，门店账号间的实际移交及实体设备试用待进行。
