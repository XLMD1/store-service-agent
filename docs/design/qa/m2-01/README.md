# M2-01 售后来源核对

2026-11-11 在回环 FastAPI、独立 PostgreSQL 与 Edge 浏览器视口完成本机技术验证，用户已完成审核。采用 C 方向页头、表单、既有原文阅读样式与选择器。照片为程序生成的虚构纸本样例。

| 页面编号 | 实测行为 | 截图 |
| --- | --- | --- |
| sources | 切换文字和照片，文件选择后看到类型及大小限制，提交后由服务器返回来源编号 | [照片表单 390px](sources-photo-390.jpg) |
| source | 照片和可选来源信息，刷新后仍通过鉴权接口读到原图 | [手机 390px](source-photo-390.jpg) · [电脑 1440px](source-photo-1440.jpg) |

两个视口均通过原文保存、照片文件选择、来源信息保存、刷新后读取和无横向溢出检查。另用独立接单账号打开他人来源，页面拒绝读取。测试使用浏览器原生文件输入和本机真实接口。

| 检查 | 结果 |
| --- | --- |
| PostgreSQL 完整回归 | 265 通过，256.84 秒。含原文和照片专项共 6 项 |
| 前端 | 68 通过，lint、类型检查及 21 文件静态 mock 构建通过 |
| 真实浏览器 | 1 项端到端测试通过，7.12 秒。覆盖 390×900 和 1440×900 |
| 文件异常 | 拒绝无效格式、截断、超限和无 CSRF 请求；磁盘写入失败时回滚元信息；原图暂缺时返回 503，同一请求补传后仍使用原编号 |
| 权限 | 当前提交者与售后权限均须满足；他人链接不可用，撤权和停用后无法读取 |

隔离测试服务使用临时端口，截图来自浏览器视口。实体手机拍照、真实原件、留存规则、OCR 及跨记录授权按[实施记录](../../../plans/m2-01-implementation.md)继续核对。
