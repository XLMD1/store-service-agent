## 设计与改动

实际复现：原库房列表位于型号、查询按钮及辅助说明之后，390px手机模式列表顶部距名称输入框底部约238px。改为同一库房字段内的一体式输入框与下拉按钮，列表以该字段为定位容器，在输入框下方6px展开；选择后收起。手机模式右侧入口46px宽，保留“选择库房”的可访问名称和键盘焦点，给名称留出更多宽度。电脑模式沿用文字入口，列表同样贴近字段。

只修改app/web/inventory.js的字段结构及app.css的对应控件样式，未更改候选选择、权限、查询请求或库存规则；移除本次结构改动后不再需要的旧窄屏纵排样式。
