## 布局、交互和复核

- [几何核对](layout-evidence.json)：390和320视口下文档宽度不超过视口，按钮最小高度44px；滚动条占用的15px不算横向溢出。
- 固定标签、明确确认复选框、键盘可见焦点；长型号/编号换行，状态徽标保持完整；没有固定底栏覆盖内容。
- 保存/提交期间冻结办理表单，避免响应返回后把新输入错误地视为已核对；独立Node回归验证等待期间冻结和失败恢复。确认错误后需按原操作核验或重新预览，不自动生成新操作重写。
- 独立审查发现的“多操作同草稿恢复选中pending回执”已复现并修复，成功草稿优先读取已成功操作。
- 本次浏览器控制台错误记录为空。截图及原型视觉证据分开维护，不将历史样板成绩复用为正式能力。
